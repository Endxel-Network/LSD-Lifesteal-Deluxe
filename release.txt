# 🫀 Lifesteal Deluxe v2.6 - Major Update Release Notes

## ✨ New Features

### 🔧 Plugin Enable/Disable System
- **NEW**: `/lifesteal enable` - Enable the entire plugin functionality
- **NEW**: `/lifesteal disable` - Disable the entire plugin functionality
- **NEW**: `plugin-enabled` config option to control plugin state
- Plugin can now be toggled on/off without restarting the server

### 🎯 Dynamic Max Hearts Configuration
- **NEW**: `/lifesteal setmaxhearts <amount>` - Set global max hearts limit in-game
- **NEW**: Real-time max hearts adjustment without config editing
- **NEW**: Automatic health updates for all online players
- **NEW**: Config persistence and server-wide notifications

### 💖 Enhanced Heart Dropping System
- **IMPROVED**: Smart heart dropping when players are at max health
- **NEW**: Hearts automatically given to killers if victim is at max health
- **NEW**: Floor dropping when killer's inventory is full
- **NEW**: `drop-to-floor` config option to control behavior

### 🎨 Configurable Heart Item System
- **NEW**: Multi-line lore support with `custom-heart-lore` list
- **NEW**: `use-half-hearts` config option (default: false for full hearts)
- **NEW**: Dynamic heart item customization in-game

## 📋 Command Reference

### 🆕 New Commands
```bash
/lifesteal enable          # Enable plugin functionality
/lifesteal disable         # Disable plugin functionality
/lifesteal setmaxhearts    # Set global max hearts limit
```

### 🔄 Updated Commands
```bash
/lifesteal help           # Enhanced help with new commands
/lifesteal info           # Shows plugin status (enabled/disabled)
/lifesteal lore           # Now supports multi-line lore
```
